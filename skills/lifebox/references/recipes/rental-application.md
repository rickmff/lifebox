# Apply for a rental home

Generic template. What landlords may ask for and which tenant protections apply depend on the
country and city. Always run the `localize` step first.

## Steps

```lifebox-steps
-60 localize   Confirm what landlords may ask for where you are moving, and the tenant protections
-45 gather     Gather the documents below as PDFs in one place
-40 budget     Work out the budget: rent, deposit, agency fees, guarantor or rent insurance
-30 apply      Visit homes and send applications
-14 review     Read the lease before signing: duration, notice period, deposit, repairs, rent increases
-7  sign       Sign, pay the deposit against a receipt, and file the lease in lifebox
0   move-in    Move in: check-in inventory with photos and meter readings
```

## Documents

```lifebox-documents
national_id          required  Passport or ID card
payslip              depends   Recent payslips or other proof of income
employment_contract  depends   Employment contract
bank_statement       depends   Recent bank statements
tax_return           depends   Last tax return
residence_permit     depends   Residence permit (foreign residents)
other                optional  References from previous landlords
other                optional  Guarantor's documents
```

## Localize

Confirm: the country and city, and whether the user is employed, self-employed or a student. Look
up which documents landlords may legally request there, deposit limits, and whether an agency fee
can be charged to tenants.

## Tips

- Share copies only with the landlord or agency, never originals, and only what the rules allow.
- File the signed lease and the deposit receipt in lifebox the same day.
